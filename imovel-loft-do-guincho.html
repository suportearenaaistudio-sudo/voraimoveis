O refúgio

O mar como
vizinho.

Um loft leve e luminoso para quem quer sentir a costa todos os dias. A sala abre-se para uma varanda protegida, com o som do Atlântico a marcar o ritmo das horas.

Prático, sereno e pronto a habitar, é uma base perfeita para fins de semana longos ou para uma vida inteira com mais horizonte.
